\subsection{Detailed Description}
background-handler providing pseudo-transparency 

this plugin provides pseudo-transparency, so you will see the \char`\"{}root-window\char`\"{} -- the desktop -- shining through, but not other windows.

properties:\begin{itemize}
\item backgroundtintalpha\item backgroundtintcolour\end{itemize}

\subsection{Detailed Description}
plugin that creates an icon. 

this is an \char`\"{}advanced\char`\"{} icon-factory that uses the \hyperlink{ic__nautilus_8c_a22}{icon\_\-set\_\-state()} method to modify icons dynamically rather than to precompute the states. this is the suggested procedure.

visually, this will create icons that look a bit like those used by the nautilus file-manager: text-labels appear below the icon-image; when selected, the text-label is underlaid with a grey box with filed off corners.

long text-labels are wrapped; for each wrap, the text-size is decreased by one.

icons may be overlaid with automatic \char`\"{}emblems\char`\"{} indicating that an item might not be accessible or writable by the current user. in the default theme, this is indicated by the stop-sign and eye of horus, respectively.

icons may be overlaid with additional textual information; at this time, the number of items contained in a folder is superimposed over the folder's icon. if the exact number of items is not known, an estimate is made (\char`\"{}123+\char`\"{} rather than \char`\"{}4711\char`\"{}). this estimate coincides with the number of folders contained in the folder (normally the number of hardlinks-2).

items that are symlinks are \char`\"{}ghosted\char`\"{}; they appear translucent.

items that evidence's thumbnailer was able to generate previews for will be show a preview in lieu of a datafile-icon.

the factory installs a variety of properties; see below. these properties can be set in themes, or from the typebuffer, e.g. 'icontextcolour ff00ff

\subsection{Detailed Description}
plugin that creates and handles a \char`\"{}rubberband\char`\"{} selection 

this selection by default looks like that in the nautilus file-manager.

the factory installs a variety of properties; see below. these properties can be set in themes, or from the typebuffer, e.g. 'rubberboxbordercolour ff00ff

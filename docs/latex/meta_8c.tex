sometimes, a meta-data entry must be created even if it is not warranted by the file we wish to describe. for instance, if no \char`\"{}genre\char`\"{} information is set on a MP3 song, we will still want to create a \char`\"{}genre\char`\"{}-entry in the meta-data so the info-dialog will create a \char`\"{}genre\char`\"{} edit-field. to do this, the provider's \hyperlink{ape_8c_a6}{meta\_\-get\_\-for\_\-file()} function should first create entries for all meta-data it can get from the file, and then call \hyperlink{meta_8c_a46}{meta\_\-dflt()} for all items that an entry must exist for \char`\"{}no matter what.\char`\"{}

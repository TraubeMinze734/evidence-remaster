\subsection{Detailed Description}
background-handler using the (deprecated) e-bg format 

ebg was the format used by the first prototype of enlightenment DR17. it lets you compose a background out of individual items such as gradients, images etc. each item can be placed/resized to fit the current resolution. this version of the plugin provides pseudo-transparency, so the items of the ebg will be laid out on a seemingly transparent window. (PT means that you will see the \char`\"{}root-window\char`\"{} -- the desktop -- shining through, but not other windows.) to compile this plugin, only edb is required, but to create your own ebgs (.bg.db), you'll need ebony, the graphical ebg-editor.

\subsection{Detailed Description}
plugin that creates and handles a \char`\"{}text-path\char`\"{} 

written by Azundris, design idea by rephorm

EXTENSIONS (icon $\ast$i)il-$>$theme-$>$areas anchors a list of all extensions for icon-list il. each of these \char`\"{}icon\char`\"{} entries describes a single extension. user1 of each of these \char`\"{}icon\char`\"{} entries contains a pointer to a theme\_\-area struct that contains function pointers, a shared object-handle, and space for extra user-data. each of these \char`\"{}icon\char`\"{} entries is likely to have one or more sub-entries of the \char`\"{}icon\_\-el\char`\"{} type that describe the rectangle-list of the extension. the user1 of each of these \char`\"{}icon\_\-el\char`\"{} entries is not used by evidence and may be used by the extensions to store pointers particular to the given rectangle. the nature of the data pointed to may vary from extension to extension.

icon +- user1\{theme\_\-area $\ast$\} theme\_\-area object $|$ +- user1,user2,user3,user4 extension-specific pointers $|$ +- lib library-handle $|$ +- ext\_\-upd, ext\_\-dst, ext\_\-evt functions in extension +- user2\{void $\ast$\} extension-specific pointer +- els\{icon\_\-el $\ast$\} rectangle list of extension $|$ +- user1\{file\_\-info $\ast$\} extension-specific pointer $|$ +- xo,yo,w,h\{int\} position and area of rectangle $|$ +- ... $|$ +- next\{icon\_\-el $\ast$\} next rectangle +- next\{icon $\ast$\} next extension

TEXTPATH each extension is described by an entry of the \char`\"{}icon\char`\"{} type. its \char`\"{}user1\char`\"{} element points to an object of the \char`\"{}theme\_\-area\char`\"{} type that contains function pointers etc. for the particular extension. a \char`\"{}textpath\char`\"{} extension will normally have a list of \char`\"{}icon\_\-el\char`\"{} elements attached to it, one for each element of the path to the current directory. each icon\_\-el will have its \char`\"{}user1\char`\"{} element pointing to the \char`\"{}file\_\-info\char`\"{} struct describing the directory referred to by the icon\_\-el in evidence's internal model of the file-system:

icon +- user1\{theme\_\-area $\ast$\} theme\_\-area object $|$ +- user1,user2,user3\{Evas\_\-Object $\ast$\} light \char`\"{}corner\char`\"{} object, dark $|$ $|$ corner, drop shadow $|$ +- user4 properties-struct $|$ +- lib library-handle $|$ +- ext\_\-upd, ext\_\-dst, ext\_\-evt functions in extension +- user2\{file\_\-info $\ast$\} dir previously shown path for $|$ (in internal model of file-system) +- els\{icon\_\-el $\ast$\} rectangle list of extension $|$ +- user1\{file\_\-info $\ast$\} file-info of referred-to dir $|$ $|$ in internal model of file-system $|$ +- xo,yo,w,h\{int\} position and area of rectangle $|$ +- ... $|$ +- next\{icon\_\-el $\ast$\} next rectangle +- next\{icon $\ast$\} next extension

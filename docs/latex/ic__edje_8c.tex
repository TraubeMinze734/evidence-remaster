\subsection{Detailed Description}
background-handler using the (new) edje format 

edje is the format used by the current prototype of enlightenment DR17. it lets you compose a background out of individual items such as gradients, images etc. each item can be placed/resized to fit the current resolution. to compile this plugin, only libedje is required, but to create your own edjes (.eet), you'll need edje\_\-cc.

!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!! With edjes that send a lot of (timer-/animation-) signals, you will notice a certain (CPU-) load. This is believed to decrease noticably once we drop GTK2. The edje plugin is provided \char`\"{}early\char`\"{} in the hopes that it may facilitate theming; load created by themes can only get lighter in future versions. !!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!

by Azundris

\subsection{Detailed Description}
background-handler using the (deprecated) e-bg format 

ebg was the format used by the first prototype of enlightenment DR17. it lets you compose a background out of individual items such as gradients, images etc. each item can be placed/resized to fit the current resolution. to compile this plugin, only edb is required, but to create your own ebgs (.bg.db), you'll need ebony, the graphical ebg-editor.

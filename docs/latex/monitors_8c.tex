create per-file events from dir-update event. 

this is a helper function. ideally, if a directory is monitored, the backend should send us individual events for each added, deleted modified item. some backends cannot do this; all they send is a change event for the directory itself. if this happens, this routine finds out what really changed and sends more specific events accordingly. \begin{Desc}
\item[Returns:]an error-code \end{Desc}
\begin{Desc}
\item[Parameters:]
\begin{description}
\item[{\em m}]the monitor that the unspecified directory-event occurred on \item[{\em tag}]the tag of the directory that changed\end{description}
\end{Desc}
